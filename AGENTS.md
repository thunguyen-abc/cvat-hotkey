# CVAT Event Hotkeys

This repo builds a Manifest V3 Chrome extension for CVAT. Read [the development guide](docs/development.md) before changing annotation handling, shortcuts, or the updater. The [Quickstart plan](docs/range-quickstart-plan.md) describes the current interaction and verification steps. Use this file and the README for the current behavior.

## Quickstart and job actions

- The panel sits under CVAT's frame input. Its header shows the zero-based position within the current job over the inclusive job size, for example `0/200` when the player is at frame 6400 in a job spanning 6400–6599. Start and End use CVAT's absolute frame numbers.
- Select All sets both absolute slider bounds together using the existing draft-discard guard. Bind Ctrl+A only in Tag annotation. CVAT 2.56.1 uses it for automatic bordering in Standard. Preserve native text selection and overlay input.
- Quickstart has a soft teal and slate surface. Start/End, range length, job position and Advanced sit above two aligned event rows. Each row offers Smoke, Drinking and Phone. One Apply button sits below the rows. Keep the panel stable across selections, errors and in-flight edits.
- The frame counter observes the player slider's `aria-valuenow`, `aria-valuemin` and `aria-valuemax`. CVAT 2.56.1 supplies these from the current frame and job bounds. Navigation updates the counter without re-reading annotations or replanning the draft. Disconnect the observer on mount abort and attach to the new slider if CVAT replaces it. [CVAT player source](https://github.com/cvat-ai/cvat/blob/v2.56.1/cvat-ui/src/components/annotation-page/top-bar/player-navigation.tsx)
- `rangeState.eventActions` maps each selected event name to `add` or `remove`. Absence means unselected. Click and Alt(+Shift)+1/2/3 use the same guarded toggle. Repeating the same direction clears it. The opposite direction is locked until deselection. Marks and draft survive remount within a job.
- Resolve event names to this snapshot’s label IDs and group them by direction for the existing planner. Apply requires a nonempty diff. A stale preview or error preserves the draft, success clears it. Advanced imports the two groups and still supports ordered operations and other source labels.
- Whole-job totals for Smoke, Drinking and Phone sit in a separate panel beside Quickstart, stacked below it on narrow screens. They are independent of the marks. Quickstart counts the same three labels from its cached range snapshot, including Start, End and unsaved changes. Range remove skips absent tags and supports frame 0.
- The small `+` and `−` buttons next to each event count apply that label over the current job bounds, independently of Start/End. Remove previews the count and asks for confirmation. Add skips deleted, filtered, and already tagged frames.
- All extension range applies, including Quickstart, Advanced and whole-job event buttons, reuse `planCVATRangeBatch` and `applyRange`. The bridge records one undo step per successful Apply in a WeakMap keyed by the loaded job instance. Its Undo and Redo compare affected frame/label pairs before replay and use tag commits in the in-memory CVAT collection. They do not call CVAT's native undo/redo actions. New Apply clears the redo branch. Restored tags may receive new IDs at Save. The journal lives in the open job session.
- CVAT Save, Auto save, and Complete & Next upload the annotation diff. Keep Clear All Tags, Apply, and replay on the existing annotation refresh path so the player stays ready on the same frame.

## Verification and release

- Run `node tests/range_plan_test.js`, `python -X utf8 tests/simulated_cvat.py`, and `node --check` on the JavaScript files you changed. The simulation covers the frame counter, slider replacement, frame-zero deletion, and whole-job event totals before marking and after applying.
- Verify the layout in simulated CVAT at desktop and narrow widths. The regression checks that the two event rows align, that the whole-job panel sits beside or below Quickstart at 1366, 390 and 320 px, and that the range counts track Apply and Undo.
- Still verify on a real test job when available. Check both `Alt+1/2/3` and `Alt+Shift+1/2/3`, that `4/5` marks the range without also toggling CVAT's native slots, that the panel is well placed during navigation, and that the frame position and whole-job counts update. The old Clear All reload report was never reproduced in simulation. Check it on a test job and record what happens before changing the bridge. Counts use `job.annotations.statistics()` with an export fallback, and live updates rely on the CVAT store notification.
- To release, bump `manifest.json`, commit and push `main`, and push the matching `vX.Y.Z` tag. The [publish workflow](.github/workflows/publish.yml) creates the ZIP and its SHA-256 sidecar. On the owner's Windows machine, the configured writable SSH remote is `git@github-abcstudio:thunguyen-abc/cvat-hotkey.git`. HTTPS origin has been usable for fetch, and push returned HTTP 403. Check workflow and release state using the GitHub API if `gh` is unauthenticated.
- Once both release assets are published, run the installed updater with `check -Confirmed` and verify `status` and the installed manifest. The updater script lives at `%LOCALAPPDATA%\CVATEventHotkeys\cvat-hotkey-updater.ps1`. Existing CVAT tabs pick up the new content scripts on their next page load. Check for unsaved annotations before refreshing an existing tab.
